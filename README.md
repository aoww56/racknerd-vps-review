## 硬件：KVM 和 RAID-10 决定了它的下限

全线 VPS 用 KVM，不是 OpenVZ。每个 VPS 跑自己的内核，内存、CPU、磁盘 IO 硬隔离，隔壁机器被挖矿脚本劫持也影响不到你。

存储是 RAID-10 纯 SSD，单盘故障不丢数据。母机用 Intel Xeon 处理器，网络走 Noction IRP 做路由优化，端口 1Gbps，独立 IPv4，开通即时。

洛杉矶 DC-05 机房部署了 60Gbps DDoS 防护。不是所有机房都有，下单时看清 location 选的是哪个。这条常被写成“全系标配”，实际按机房区分。

## 线路：163 线路，这是最该扣分的地方

RackNerd 默认走普通国际线路（163），不是 CN2 GIA 专线。晚高峰北京时间 20:00 到 23:00，国内访问美西节点会波动。这是 163 线路的通病，同价位用这条线的商家都一样。

洛杉矶 DC-02 做过亚洲优化，电信联通移动三网往返直连，是国内用户相对最优的节点。圣何塞、达拉斯波动更明显。

2022 年有一篇西雅图机房的实测（$12.99/年，1 核 1GB，15GB SSD），晚 8 点测速的结论是“上行速度一般，下行速度还可以”，本地 SFTP 上传 8.9MiB/s、下载 9.7MB/s，超级 ping 基本全绿但“部分地方的网络丢包还是比较多的”，回程电信绕圣何塞进广州。作者的建议是：用途主要是面向大陆用户的网站要慎重。这组数据是 2022 年的，不能当 2026 年的现状看，但 163 线路晚高峰的这个特征至今没变。

线路这关怎么过，看用途。对国内晚高峰延迟敏感的（面向大陆用户的站点、实时性要求高的服务），RackNerd 不是最优解。代理中转、海外业务、备份节点、个人练手，这条线路够用。

## 买完之后会碰到的几件事

- **升级可以，降级不行**。SolusVM 面板里随时升到更高一档，只需一次重启，停机约一分钟。降级不支持，买之前想清楚配置。
- **没有自动备份**。VPS 不提供自动备份，得自己 rsync 到另一台机器，或用 rclone 推到对象存储。共享主机才送每日 JetBackup。RAID-10 能扛单盘故障，扛不了误删和账号被盗。
- **非托管**。工单只管账务和基础设施相关的问题，不会教你装 Nginx、配防火墙。Linux 基础得自己有，或者现学。
- **控制面板**。文档里写的是 SolusVM，能重装系统和看 VNC，也能设 rDNS；官网最新的 VPS 特价页另提到 ctrl 面板，带一键应用和网络防火墙。下单页写哪个就是哪个。
- **2FA 建议开**。客户区支持两步验证。它支持支付宝付款，账号被盗意味着对方能直接用你的支付方式开机器。
- **额外 IP 每月 $1**。需要多个 IP 的场景要算进成本。
